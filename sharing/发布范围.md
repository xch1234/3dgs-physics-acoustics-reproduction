# 发布范围与本地目录对应

此公开仓库来自独立发布副本 `_publication/github`，未搬动或删除原工作目录。发布副本调整首页/导航、给历史结论加说明，修复归档文档相对链接，移除计划中的个人考试安排；不改变科学代码、指标或历史实验结果。

## Git 仓库

本地包装与数值代码、参数、报告、环境记录、验证程序/命令/日志、12 段视频、WAV 音频及摘要图。保留原三篇论文目录结构。根目录 `查看效果.html` 与 `查看与复跑指南.md` 是新增的队友入口。

`publication-inventory.json` 逐文件记录原路径、大小和发布分类（git / release / external）。此表是打包前原始文件选择记录；新增发布文档、README 提示与链接调整另见本说明。Git 本身记录发布文本的确切内容。

## GitHub Releases

`verified-2026-11-01` 保存大数组、逐帧图、训练模型及优化器检查点，包括历史负例/试跑和独立验证的新产物。`artifacts-*.zip` 是去重数据块分包，`artifacts.json` 记录原路径、文件大小、SHA-256 和分包映射。

用 `python tools/restore_artifacts.py --prefix ...` 恢复，或 `--all` 恢复全部。原始科学文件不做压缩有损转换，也不把完整检查点替换成只有网络权重；相同数据块只存一次，恢复到每个原路径。单独提供 `ficus-30000.ply` 便于查看，无需解开整个训练目录。

原报告链接到大文件时，GitHub 网页可能显示文件不存在；这类文件需要恢复后才能在本地访问，不能把它解释成 Git 树已经包含所有结果。可用 `--list` 查询路径。

原文档中的 Windows/WSL 绝对路径是历史命令证据，不是下载后可直接使用的路径。Linux 环境重建、新机器兼容性和全论文复现仍受独立验证报告所列限制。
