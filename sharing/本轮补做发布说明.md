## 恢复本轮原始结果

需要 Python 3.11+。在仓库根目录：

```bash
python tools/restore_artifacts.py --manifest sharing/remediation-artifacts.json --list
python tools/restore_artifacts.py --manifest sharing/remediation-artifacts.json --prefix remediation_20261101/physics/outputs/ficus_anisotropy/
# 全部本轮大文件（需要下载分包并留出恢复文件空间）
python tools/restore_artifacts.py --manifest sharing/remediation-artifacts.json --all
```

默认 `sharing/artifacts.json` 仍用于旧 Release；用 `--manifest` 明确选择本轮。两次发布的分包名称不同，不会混用缓存。下载块和重建文件都有 SHA-256 校验，现存不同内容会被拒绝覆盖。完整恢复还需要缓存空间，建议为本轮预留至少 40 GiB。

原报告中指向逐帧图、数组、模型的相对链接，需恢复后才可在本地打开；GitHub 网页中这些路径不在 Git 树内。`--list` 可查询它们，并非没有上传。历史 `verification_20261101` 所需大文件使用旧清单另行恢复。
