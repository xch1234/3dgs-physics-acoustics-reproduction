# 可选各向异性正则项实验协议

2026-11-01，在新增训练启动前固定。依据 PhysGaussian §3.8 式(12) 与 PDF 第 8 页图8，实现 `mean(max(max(scale)/min(scale), r) - r)`。当前固定版本上游 3DGS train.py 未包含该项，先前完成的是未正则化基线。

本地受控设置：r=5，权重 λ=0.01，固定上游随机种子与现有 Ficus 输入，800×800、100 train / 200 test、30,000 步，原优化参数及密化规则保持。原文未公开匹配的 r/λ 与图8凳子训练数据，所以这不是原图8数值复现；这两个参数是预先选择的本地方法验证值，不根据测试成绩重选。

使用仓库外 AST 适配器，只在上游唯一 photometric loss 赋值处加上该项；原 train.py 保持未修改，源哈希与变更行号另存。保存每千步原图像损失、正则损失和轴比统计。开始前检查已知值、梯度有限差分、无激活时零梯度、各向同性零惩罚和整体尺度不变性。

与已保存未正则化 30,000 步模型比较独立测试 PSNR/SSIM/LPIPS 及所有高斯轴比，不用测试集选择检查点。另使用相同完整 Ficus 配置模拟新增模型，检查全部帧与状态；不能把轴比降低直接等同于动态视觉质量或物理精度改善。

新增输出目录为 `outputs/ficus_anisotropy` 和 `outputs/ficus_anisotropy_full`，原模型、检查点、图像与实验数据保留。使用现有 Linux Conda，所有新增缓存和输出在项目内。完整命令与结果将在实际运行后补充。
