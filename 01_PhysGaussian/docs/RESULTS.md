# PhysGaussian 官方物理模块复现结果

运行上游提交 `8339ed6aa2cd5d50e1001a254a3d95aea678a956` 未修改的 MPM_Simulator_WARP 和 compute_cov_from_F，在 RTX 2050 上推进 192 个材料点 / 高斯。网格 32³，dt=0.0002 s，两组弹性模量分别 20 kPa / 80 kPa，各 2000 步。

## 验证

- 无边界自由落体平均位置误差：2.344e-07 m；按半隐式 Euler 的离散解析解比较。
- 零重力静止态最大位置误差：0.000e+00 m。
- Σ=FΣ₀Fᵀ：独立 NumPy 与官方 Warp 核最大相对差 8.393e-08。
- 两组所有输出时刻协方差正定、变形梯度有限且未翻转；粒子总质量恒定。
- 软/硬梁最大端部下挠：0.256964 / 0.147108 m。

## 复现层次

这是官方物理求解与高斯运动学模块复现，输入为本地合成梁，不是论文照片重建场景。渲染为本地正交投影的各向异性高斯 alpha 合成，仅用于诊断，没有训练外观、SH、透视相机、原 CUDA 光栅器或论文画质指标。图像不能冒充原官方端到端渲染结果。
PyTorch 使用 CPU 包以满足官方导入；实际物理计算由 Warp CUDA 执行。核调用和输入适配在上游仓库外，未改作者源文件。
