# 官方网格的实际神经振动混合求解

冻结已训练 defaultUnet，输入作者 example.obj 的 3863 体素网格。用稀疏 K/M 在 17,898 自由度上做原 LOBPCG 严格双精度精修，未为节省显存替换成小网格。此几何不属于长方体训练族。

- random：7024 次迭代，特征值最大相对误差 2.78e-12，最大模态相对残差 3.64e-07，收敛标记 True。
- untrained_network：2897 次迭代，特征值最大相对误差 2.75e-12，最大模态相对残差 3.37e-07，收敛标记 True。
- trained_network：10000 次迭代，特征值最大相对误差 6.38e-05，最大模态相对残差 0.000496，收敛标记 False。

迭代预算 10000；这是在原 2000 步未通过残差后增加预算的独立收敛诊断，原结果保持。未训练或调整网络。
