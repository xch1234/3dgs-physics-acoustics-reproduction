# 官方网格的实际神经振动混合求解

冻结已训练 defaultUnet，输入作者 example.obj 的 3863 体素网格。用稀疏 K/M 在 17,898 自由度上做原 LOBPCG 严格双精度精修，未为节省显存替换成小网格。此几何不属于长方体训练族。

- random：2000 次迭代，特征值最大相对误差 4.88e-06，最大模态相对残差 0.00169，收敛标记 False。
- untrained_network：2000 次迭代，特征值最大相对误差 3.97e-06，最大模态相对残差 0.000178，收敛标记 False。
- trained_network：2000 次迭代，特征值最大相对误差 0.00017，最大模态相对残差 0.000216，收敛标记 False。
